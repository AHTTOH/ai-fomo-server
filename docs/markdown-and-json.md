## 마크다운(Markdown)이란?

기호 몇 개로 글을 구조적으로 꾸미는 문법입니다.[^1]

워드에서 "제목" 버튼 누르는 대신, `#` 하나만 앞에 붙이면 제목이 됩니다. 지금 이 가이드도 마크다운으로 작성됐어요. Notion, GitHub, Discord, 티스토리 등 대부분의 플랫폼에서 지원합니다.[^2]

**자주 쓰는 문법**

```
# 제목1
## 제목2

**굵게**
*기울임*

- 목록1
- 목록2

1. 번호목록
2. 번호목록

> 인용문

`코드 한 줄`

[링크텍스트](https://주소)
```

실제로 어떻게 보이냐면:

- `**굵게**` → **굵게**
- `*기울임*` → *기울임*
- `# 제목` → 큰 제목으로 표시

AI한테 무언가 물어볼 때 "마크다운으로 정리해줘" 라고 하면 AI가 이 형식으로 깔끔하게 답변을 줍니다.  반대로 AI 답변을 노션에 붙여넣으면 서식이 그대로 살아요.[^3]

## JSON이란?

프로그램끼리 데이터를 주고받을 때 쓰는 형식입니다.[^4]

"제이슨"이라고 읽어요. 생긴 건 이렇게 생겼습니다.

```json
{
  "이름": "홍길동",
  "나이": 30,
  "관심사": ["AI", "자동화", "코딩"],
  "재직중": true
}
```

구조는 단순합니다. **키(이름표) : 값** 쌍으로 이루어져 있어요.[^4]

- 텍스트는 `"따옴표"` 로 감쌈
- 숫자는 그냥 숫자
- 목록은 `[대괄호]`
- 참/거짓은 `true` / `false`

**왜 알아야 하나요?**

ChatGPT API, Telegram 봇, 자동화 툴 등 거의 모든 API가 JSON 형식으로 데이터를 주고받습니다.  AI한테 "결과를 JSON 형식으로 줘" 라고 하면 코드에서 바로 꺼내 쓸 수 있는 형태로 줍니다.[^5]

예를 들어 AI 자동화 워크플로우에서:

```json
{
  "action": "send_message",
  "to": "홍길동",
  "message": "보고서 완성됐습니다"
}
```

이런 식으로 AI가 다음 행동을 지시하는 데이터를 JSON으로 넘겨요.

## 한줄 정리

- **마크다운** = 기호로 글을 꾸미는 문법. 노션·디스코드·GitHub 어디서나 씀
- **JSON** = 프로그램끼리 데이터 주고받는 형식. API 쓸 때 반드시 마주침
